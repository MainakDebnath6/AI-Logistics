# Pre-registration 2: relative-freshness test (written BEFORE any run of this experiment)
Background (from experiment 1, already reported): the AR h=28 reversal (pooled cheaper than HCCR) needs persistent residuals; fresh (non-deployable) calibration data removes most of it; adding staleness to BOTH policies did not erode HCCR's h=1 advantage. Hypothesis H-RF (relative freshness): pooled calibration is better at long horizons because its window mixes fresh short-horizon residuals, which HCCR's h-day-old horizon-h window lacks.
Intervention (ALL conditions deployable/non-anticipative): stale ONLY the pooled policy's calibration information by S days (every pooled window origin set shifted back by S; HCCR natural, forecasts, demand, costs, fleet, W=200, 27-set pool unchanged). Controls: stale ONLY HCCR by S.
Estimand: Delta_h = C_pooled - C_HCCR (positive: HCCR cheaper), ungated, AR family, paired by seed with common random numbers.
PRIMARY contrast (h=14 and h=28 separately, Holm over 2): Psi_h = [Delta_h(pooled staled by S=28) - Delta_h(natural)]_{phi=0.95} - [same]_{phi=0}.
Predictions fixed now: H-RF => Psi_14 > 0 and Psi_28 > 0 (staling the pooled policy should help HCCR relatively, only under persistence). Alternative H-sample (pooled wins through larger effective sample, not freshness) => Psi ~ 0 because staling does not change pooled's sample size. Alternative H-stationary (windows equally informative if residuals stationary) => Psi ~ 0 at phi=0 and small at phi=0.95.
Secondary/exploratory (uncorrected): dose-response in S in {14, 28} for stale-pooled; stale-HCCR-only at S=28 (H-RF predicts Delta decreases, most at h=1); disagreement, capacity, reserve cost, unmet.
Inference: percentile bootstrap (10,000, seed 12345) over simulations; Wilcoxon p for Holm; minimum practically meaningful effect 0.10 cost units (design choice); alpha 0.05; power 0.80.
Sample size: pilot of 30 simulations (seeds 400-429) ONLY for implementation check and paired-sd estimation; N = smallest N in {30,40,60,80,100,150} with simulated power >= 0.80 for MPE 0.10 on BOTH primary contrasts (mechanism/power.simulated_power on pilot Psi differences), then x1.5 for variance-estimation uncertainty, capped at 150 by compute. Confirmatory seeds 500+; no peeking. Exclusions: only solver/numerical failures, counted and reported.
Interpretation rules: Psi_28 and Psi_14 CIs > 0 -> supports H-RF (subject to the phi/dispersion confound); CIs include 0 with adequate power (CI half-width < MPE) -> H-RF not supported; wide CI -> inconclusive. A positive Psi is evidence of relative freshness only within this simulator.
