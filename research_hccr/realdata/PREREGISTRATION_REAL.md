# Pre-registration 3: real-data check on public bike-sharing demand (written BEFORE any real-data forecast, decision or cost was computed)
Data: UCI "Bike Sharing" (Fanaee-T & Gama; Capital Bikeshare, Washington D.C.; CC BY 4.0; DOI 10.24432/C5W894). Files day.csv/hour.csv obtained 2026-10-12 from the GitHub mirror udacity/deep-learning (official UCI host unreachable from the sandbox); SHA-256 recorded in data/SHA256SUMS.txt. Integrity audit before analysis: 731 continuous days (2011-01-01..2012-12-31), no duplicates, hourly sums equal daily counts exactly.
Semantics/limits: counts are FULFILLED rentals (supply-censored demand), one city, two years. There are NO regions, vehicle capacities, orders or routes: the real-data check evaluates forecasting calibration, reserve-set choice, normalised reservation cost and shortfall ONLY; routing and feasibility are NOT evaluated.
Segments (not geographic regions): four hour-of-day bands (night 0-5, morning 6-10, midday 11-15, evening 16-23), daily rental counts per band from hour.csv, each rescaled so its mean over the initial-fit period equals 100 model units (rescaling factor from days 0-364 only). Segments share weather shocks, so they are NOT independent: inference resamples time blocks jointly over segments.
Causal protocol (day indices, 0 = 2011-01-01): initial fit days 0-364 (one full year, needed for annual terms); residual calibration origins 365-539; validation origins 540-599 (selects only the fixed-buffer fraction); test origins 600-702 (103 origins, evaluated once; targets <= day 730); horizons h in {1,7,14,28}; weekly refit; calibration window W=150 (shorter than the simulator's 200 because the data are short; a declared deviation); capacity kappa=1.05 x initial-fit mean; same 27-set reserve pool and cost structure as the paper; policies ungated (the gate was unsupported in the simulator): reactive, point, buffer, pooled, HCCR, robust(q=0.95 fixed a priori), oracle (unattainable).
Cost: normalised scenario objective (NOT monetary). Shortage penalty through the critical-fractile grid pi in {1, 2, 4, 9, 19} (alpha = pi/(pi+1) approx {0.5, 0.67, 0.8, 0.9, 0.95}); PRIMARY pi=4 fixed now; all values reported.
Estimand: Delta_h = C_pooled - C_HCCR per test origin (mean over segments), mean over origins; positive = HCCR cheaper. Uncertainty: moving-block bootstrap over test origins, block length 28 days (covers horizon overlap and weather persistence), 10,000 resamples, seed 12345, 95% percentile CI. No hypothesis test is claimed; this is a descriptive external check with one realisation of one city (effective sample is small).
Practical-significance threshold (design choice): |Delta| >= 1% of HCCR's mean cost at the same h and pi.
Predictions (from the simulation study, stated as expectations only): (i) |Delta| small; (ii) reserve-set disagreement between HCCR and pooled mostly below ~20%; (iii) no consistent sign across horizons. Any outcome is reported. Hurricane Sandy (2012-10-29, test period) is NOT excluded.
Exclusions: none planned.
